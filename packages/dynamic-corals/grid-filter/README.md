# grid-filter

sitetile's `%% sitetile: grid filter=<all-label> %%` facet bar. The renderer
(`packages/emit/grid.mjs`) writes every card and a bar of pills, one per distinct card badge, with
the mount point on the bar; this coral makes a pill show only the cards whose `data-cat` matches it
(the first, empty-valued pill shows all). Scoped to the bar's own `.st-grid`, so two filtered grids
on one page do not cross-talk. Without JS every card shows.

Local-only (no registry channel): sitetile's `Grid.astro` imports the client source and Astro
bundles it into the page; `grid-filter.js` is the built artifact for a host that serves corals itself.

## grid-filter metadata

Makes a grid's facet pills show only the cards in the chosen facet.

Author: `official`.

Host: `sitetile`. Renderer output, not a standalone copy-paste embed. The renderer emits the mount point and the section's markup; sitetile's section component imports the client source and Astro bundles it into the page, and a Worker host serves the built artifact itself.

### Embed

```html
<section class="st-grid"><div class="st-grid-filter" data-dynamic-coral="grid-filter" role="group" aria-label="All"><button type="button" class="st-filter-pill is-active" data-cat="" aria-pressed="true">All</button><button type="button" class="st-filter-pill" data-cat="Brand" aria-pressed="false">Brand</button></div><div class="st-cells"><div class="st-cell" data-cat="Brand">One</div></div></section>
<script src="grid-filter.js"></script>
```

### Attributes

| Attribute | Type | Required | Default | Purpose |
|---|---|---|---|---|
| `data-dynamic-coral` | enum | yes | — | Selects the grid-filter coral; on the filter bar inside a .st-grid. Values: `grid-filter`. |
| `data-cat` | string | no | `` | On each pill and card: its facet. A pill with an empty value shows every card. |
