# hero-parallax

sitetile's `%% sitetile: hero layers=back|front parallax %%` depth effect. The renderer
(`packages/emit/hero.mjs`) writes the stacked layer images and, only when `parallax` is set, the
mount point on the section; this coral drifts each layer on pointer-move and scroll, scaled by its
`data-depth`, and eases back to centre when the pointer leaves. It does nothing under
`prefers-reduced-motion: reduce`. Without JS the layers simply sit still.

Local-only (no registry channel): sitetile's `Hero.astro` imports the client source and Astro
bundles it into the page; `hero-parallax.js` is the built artifact for a host that serves corals itself.

## hero-parallax metadata

Drifts a layered hero's images on pointer and scroll, front layers more; off under reduced motion.

Author: `official`.

Host: `sitetile`. Renderer output, not a standalone copy-paste embed. The renderer emits the mount point and the section's markup; sitetile's section component imports the client source and Astro bundles it into the page, and a Worker host serves the built artifact itself.

### Embed

```html
<section class="st-hero st-hero-layered" data-dynamic-coral="hero-parallax"><div class="st-hero-stage" aria-hidden="true"><img class="st-hero-layer" src="back.webp" alt="" data-depth="0"><img class="st-hero-layer" src="front.webp" alt="" data-depth="1"></div></section>
<script src="hero-parallax.js"></script>
```

### Attributes

| Attribute | Type | Required | Default | Purpose |
|---|---|---|---|---|
| `data-dynamic-coral` | enum | yes | — | Selects the hero-parallax coral; on the layered hero section. Values: `hero-parallax`. |
| `data-depth` | number | no | `0` | On each .st-hero-layer: its back-to-front index. Front layers drift more. |
