# carousel

sitetile's `%% sitetile: carousel %%` runtime. The renderer (`packages/emit/carousel.mjs`) writes
the track, its cells and the prev/next buttons, with the mount point on the section; this coral
makes the buttons scroll by a whole number of cells, disables them at either end or when nothing
overflows, honours the track's `data-start`, and sizes the row to the tallest VISIBLE cell (re-run
when images and fonts settle). Without JS the track still scrolls natively.

Local-only (no registry channel): sitetile's `Carousel.astro` imports the client source and Astro
bundles it into the page; `carousel.js` is the built artifact for a host that serves corals itself.

## carousel metadata

Wires a carousel's prev/next buttons, overflow state and visible-cards height.

Author: `official`.

Host: `sitetile`. Renderer output, not a standalone copy-paste embed. The renderer emits the mount point and the section's markup; sitetile's section component imports the client source and Astro bundles it into the page, and a Worker host serves the built artifact itself.

### Embed

```html
<section class="st-carousel" data-dynamic-coral="carousel"><div class="st-car-viewport"><button class="st-car-nav st-car-prev" type="button" aria-label="Previous">‹</button><div class="st-car-track" data-start="0"><div class="st-car-cell">One</div><div class="st-car-cell">Two</div></div><button class="st-car-nav st-car-next" type="button" aria-label="Next">›</button></div></section>
<script src="carousel.js"></script>
```

### Attributes

| Attribute | Type | Required | Default | Purpose |
|---|---|---|---|---|
| `data-dynamic-coral` | enum | yes | — | Selects the carousel coral; on the carousel section. Values: `carousel`. |
| `data-start` | number | no | `0` | On .st-car-track: the 0-based card the track first rests on. |
